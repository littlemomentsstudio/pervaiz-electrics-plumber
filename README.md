# Pervaiz Electrics & Plumber — multi-page website

## Pages
- `index.html` — Home
- `about.html` — About the business and work approach
- `services.html` — Services and indicative price list
- `contact.html` — Contact details and WhatsApp inquiry form

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. For best results, use Live Server: right-click `index.html` and select **Open with Live Server**.
4. Opening `index.html` directly also works; Google Fonts require an internet connection.

## Editing
- Replace the full shop address placeholder only when the correct address is available.
- Phone links use `tel:+923459160307`; WhatsApp uses `https://wa.me/923459160307`.
- Prices in `services.html` are estimates only, not confirmed business rates. Adjust them after the owner decides actual rates. Labour/material scope and visit fee should be agreed before work starts.
- English/Urdu translations are in `script.js`; Urdu sets page direction to RTL. The selected language is remembered in the browser.
- The contact form opens WhatsApp with a pre-filled message; it does not send automatically.
- The wordmark is built in HTML/CSS.
- Images are crops from the previously generated mockup screenshot, not original full-resolution photography.
